# SNIT Bug Bounty Hunting & Web Application Security Labs

Welcome to the SNIT Bug Bounty Labs repository.

This repository is designed for students, cybersecurity enthusiasts, aspiring ethical hackers, and security professionals who want to develop practical skills in Bug Bounty Hunting and Web Application Security Testing.

## About This Project

The project provides structured, hands-on training covering the complete bug bounty methodology, from understanding program scope and reconnaissance to identifying vulnerabilities, validating findings, and preparing professional security reports.

## Learning Objectives

- Understand Bug Bounty Hunting and responsible disclosure.
- Learn web application security fundamentals.
- Perform authorized reconnaissance and asset discovery.
- Identify web application technologies and services.
- Understand OWASP Top 10 vulnerabilities.
- Practice vulnerability identification in controlled lab environments.
- Analyze HTTP requests and responses.
- Use professional web security testing tools.
- Prepare vulnerability reports with supporting evidence.

## Responsible Disclosure & Safety

All practical activities must be performed on systems owned by the student, intentionally vulnerable training applications, or targets explicitly authorized by their owners.

Students must follow bug bounty program scope, testing rules, rate limits, and responsible disclosure requirements.

Unauthorized access, destructive testing, denial-of-service testing, and accessing other users' private data are prohibited.
